**编年原则**：以《三国志》正文为主要依据。不同史料发生冲突时，优先采用《三国志》正文；裴松之注、《资治通鉴》《晋书》用于补充正文未载、但对理解历史进程有价值的重要事件。

**颜色标记**：

- 三国志：《三国志》正文。
- <span class="src-pei">裴松之注</span>：裴松之注文及其所引史料。
- <span class="src-zztj">资治通鉴</span>：《资治通鉴》补充。
- <span class="src-jinshu">晋书</span>：《晋书》补充。

**加粗**表示对政权兴亡、政治格局或战争进程具有重要影响的事件；一般人物生卒、官职变动不一律加粗。

年表不要求逐年列事，只在有值得记录的事件时设立条目。汉末部分用于交代三国形成的历史背景；三国时期以魏、蜀、吴并列；蜀、魏灭亡后继续记载吴与晋的历史，至 **280 年东吴灭亡** 为止。

## 后汉末年

| 公元 | 年号 | 重要事件 |
| :-: | --- | --- |
| 184 | 中平元年 | **黄巾起义**爆发，张角、张宝、张梁率众起事。曹操任骑都尉，参与讨伐颍川黄巾，刘备、孙坚亦参与镇压黄巾军。 |
| 189 | 中平六年 | 灵帝崩，何进被杀，袁绍诛灭宦官。**董卓入京，废少帝、立献帝**。曹操逃离洛阳，至陈留散财合兵。 |
| 190 | 初平元年 | 关东州郡起兵讨董卓，推袁绍为盟主。曹操在荥阳汴水败于徐荣；孙坚击破董卓军。董卓挟献帝迁都长安，焚毁洛阳宫室。 |
| 192 | 初平三年 | **王允、吕布诛杀董卓**；李傕、郭汜攻入长安，王允被杀，吕布出奔。孙坚攻刘表，战死。曹操领兖州，收降青州黄巾，编为青州兵。 |
| 194 | 兴平元年 | 曹操再征陶谦；张邈、陈宫迎吕布袭取兖州，曹操回军争夺。陶谦病死，刘备领徐州。刘焉死，刘璋继任益州牧。 |
| 195 | 兴平二年 | 曹操击败吕布，吕布东奔刘备。献帝东归，李傕、郭汜追击。孙策渡江，开始经营江东。 |
| 196 | 建安元年 | 献帝回到洛阳。**曹操迎献帝至许县，迁都许**，任司空、行车骑将军，逐步取得朝廷主导权。吕布袭取下邳，刘备依附曹操，后任豫州牧。 |
| 198 | 建安三年 | **曹操围攻下邳，擒杀吕布**，陈宫、高顺同死。孙策受封讨逆将军、吴侯。 |
| 199 | 建安四年 | **袁绍攻灭公孙瓒**。袁术病死。张绣归降曹操。孙策击破刘勋，继续扩张江东势力。 |
| 200 | 建安五年 | 董承等谋诛曹操，事泄被杀。刘备袭杀徐州刺史车胄，占据徐州，后败走投袁绍。关羽暂归曹操，斩颜良后离去。孙策遇刺身亡，孙权继位。**官渡之战，曹操袭烧乌巢粮谷，大破袁绍**。 |
| 201 | 建安六年 | 刘备为曹操所败，转投刘表，屯驻新野。 |
| 202 | 建安七年 | 袁绍病死，袁谭、袁尚争夺继承权，河北局势进一步分裂。 |
| 204 | 建安九年 | **曹操攻破邺城**，逐步控制冀州。袁尚、袁熙退走。 |
| 207 | 建安十二年 | **曹操北征乌桓，白狼山之战斩蹋顿**；袁尚、袁熙逃往辽东，后被公孙康斩杀。刘备三顾诸葛亮。 |
| 208 | 建安十三年 | 曹操任丞相。刘表死，刘琮降曹操；刘备在长坂败退，赵云护刘禅脱险。诸葛亮出使东吴。**赤壁之战，孙刘联军大破曹操**。孙权攻合肥，未能攻克。 |
| 209 | 建安十四年 | 周瑜围攻江陵，曹仁退走。刘备取得荆南数郡，领荆州牧，治公安；孙权与刘备联姻。 |
| 211 | 建安十六年 | **曹操在潼关击败马超、韩遂，控制关中**。刘璋迎刘备入蜀，刘备率军进入益州。 |
| 213 | 建安十八年 | **曹操受封魏公，加九锡，建立魏国**。刘备与刘璋决裂，在益州展开争夺。 |
| 214 | 建安十九年 | **刘备攻取成都，刘璋投降，刘备领益州牧**。庞统此前在攻雒县时中流矢身亡。孙权攻取皖城，并遣吕蒙夺取长沙、零陵、桂阳。 |
| 215 | 建安二十年 | **曹操征张鲁，汉中归魏**。孙权围攻合肥，张辽率兵突击，孙权退兵。刘备与孙权重新划分荆州辖区。 |
| 216 | 建安二十一年 | **曹操进爵魏王**。冬，曹操南征孙权。 |
| 217 | 建安二十二年 | 曹操与孙权在濡须一带交战，双方各自退兵。**曹丕被立为魏太子**。鲁肃去世，吕蒙代领其军。 |
| 219 | 建安二十四年 | **刘备平定汉中，自称汉中王**。黄忠斩夏侯渊于定军山。关羽北攻樊城，水淹七军，擒于禁、斩庞德；孙权遣吕蒙袭取荆州，关羽败走被杀。此役后，刘备集团失去荆州根据地。 |
| 220 | 建安二十五年 | **曹操去世**，曹丕继任魏王。法正、黄忠等人去世。 |

## 西晋与东吴

## 史料使用说明

- **《三国志》正文**：年表的基本叙事框架。人物活动、政权纪年、战争胜负及重要政治事件，优先依正文。
- **裴松之注**：用于补充正文未载的轶事、异说和相关史料。注文所引材料之间也可能互有矛盾，不将单一注文直接视为定论。
- **《资治通鉴》**：用于补足编年脉络、事件先后及魏晋之际的政治军事变化；若与《三国志》正文抵牾，以《三国志》正文为准。
- **《晋书》**：主要用于补足魏亡以后西晋与东吴的交涉、战争及吴亡经过。其记载属于后出史料，使用时与《三国志》正文区别。
- **颜色标记表示该条主要采用的史料来源，不代表史料价值高低，也不意味着同一事件只见于一种史书。** 若事件可由多种史料互证，标记以本条主要采用的叙事来源为准。
