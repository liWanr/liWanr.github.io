| 217 | 建安22 | 曹操进军濡须口，孙权退走。 |
| 218 | 建安23 | 曹彰讨伐代郡乌桓。鲜卑轲比能投降，北方安定。刘备出兵阳平关，曹操出兵长安。 |
| 219 | 建安24 | 刘备在定军山斩夏侯渊。曹操出斜谷，不克而还。**刘备平定汉中→自称汉中王**。**关羽被孙权所杀**。孙权任骠骑将军。 |
| 220 | 建安25 | **曹操去世**，终年66岁。曹丕继位。黄忠去世。 |
